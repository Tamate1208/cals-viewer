# 広島県公共工事 電子納品検査ビューア (CALS Inspector)

土木公共工事（広島県および国土交通省の電子納品要領・CALS/EC基準）の完了検査・中間検査において、電子納品データを素早く・直感的に閲覧・照合できるブラウザベースの検査支援アプリです。

**インストール作業や管理者権限は一切不要。単一のHTMLファイル（`広島県電子納品検査ビューア.html`）をブラウザで開くだけで即座に起動します。**

---

## 🌟 主な特徴

1. **完全インストール不要（スタンドアロン単一HTML）**
   * アプリの全プログラム・デザイン・アイコン・解析処理が「たった1つのHTMLファイル」に内蔵されています。
   * PCのセキュリティ制限（.exe 実行禁止など）に引っかからず、Edge / Chrome / Safari 等でダブルクリックするだけで起動。
2. **階層を問わないINDEX_C.XML ＆ 書類・写真XMLの全自動検出**
   * 工事完成図書のフォルダ（親フォルダや任意のフォルダ名）を指定するだけで、配下のサブフォルダから `INDEX_C.XML` を自動探索。
   * 紐づく `PHOTO/PHOTO.XML`（写真）、`REPORT/REPORT.XML`（報告書）、`DRAWING/DRAWING.XML`（図面）を自動で一括パースして読み込みます。
3. **左側「検査対象ツリーナビゲーション」による高効率な選択**
   * 画面左端に常駐するツリービューから、書類種別（打合せ簿、計画書、試験表、完成図面等）や工種・写真区分（着工前、施工中、完成等）を階層ツリーで一発選択。
   * クリックした対象が中央の書類プレビューや右側の写真プレビューに即座に連動します。
4. **書類と写真の左右分割（デュアル）突合ビュー**
   * **中央ペイン**: 報告書（打合せ簿・施工計画書・試験成績表など）や完成図面
   * **右ペイン**: 工事写真（高解像度プレビュー・電子黒板情報）
   * 境界線をドラッグして幅を自由に変更でき、書類の記載内容と実施工写真を並べてスムーズに突き合わせ検査ができます。
5. **Shift-JIS / UTF-8 自動判別**
   * 広島県・国交省の電子納品基準で標準的な Shift-JIS (CP932) の XML（`INDEX_C.XML`, `PHOTO.XML`, `REPORT.XML`, `DRAWING.XML`）を文字化けなく高精度にパース。
6. **あらゆる端末・タブレット対応**
   * PCでのフォルダ指定（`webkitdirectory`）およびドラッグ＆ドロップに対応。
   * iPadなどのタブレット向けに**ZIPファイル一括解凍・読込**にも標準対応。
7. **検査支援（確認チェック・指摘メモ ＆ 調書エクスポート）**
   * 各アイテムに「適（確認済）」「要確認（指摘あり）」と指摘メモをその場で記録。
   * 検査終了時に、指摘事項一覧を **Excel用CSV** または **印刷用A4検査調書（PDF保存可）** で出力。

## 🚀 使い方

### 1. アプリの起動
* プロジェクトフォルダ内の **`広島県電子納品検査ビューア.html`** をダブルクリックして開きます。
  （Microsoft Edge, Google Chrome, Safari などのブラウザで自動起動します）

### 2. 電子納品データの読み込み
* **納品フォルダを選択**: 電子納品のルートフォルダ（`INDEX_C.XML` が入ったフォルダ）を選択。
* **ZIPファイルを選択**: 電子納品一式を圧縮した ZIP ファイルを指定（タブレット等で便利）。
* **サンプルデータで試す**: ボタンを押すと、広島県の道路改良工事を模した模擬電子納品データ（写真・電子黒板・打合せ簿・試験表・図面）が読み込まれ、すぐに機能を試せます。

### 3. 検査・閲覧操作
* **画面上部**: 工事情報、発注者、進捗率の確認、画面表示モード切替（左右分割／書類のみ／写真のみ）。
* **左ペイン（書類）**: タブで「報告書類」「図面」「工事概要」を切り替え。PDFや書類をインラインプレビュー。
* **右ペイン（写真）**: 写真区分（着工前／施工中／完成／不可視部）や工種で絞り込み。拡大ズームや電子黒板の測定値を確認。
* **検査判定**: 各アイテム下の「確認済 (適)」または「要確認・指摘」ボタンを押し、必要に応じて指摘メモを入力。

### 4. 検査調書の出力
* ヘッダー右上の **「検査調書・出力」** ボタンをクリック。
* 指摘事項一覧のサマリーが表示され、**「CSV出力」**（Excelでそのまま開ける形式）または **「印刷 / PDF」** で検査調書を保存・印刷できます。

## 💻 開発・ビルド方法

Node.js 環境での開発・再ビルド手順：

```bash
# 依存関係のインストール
npm install

# 開発用ローカルサーバーの起動 (HMR)
npm run dev

# スタンドアロン単一HTMLのビルド
npm run build
# -> dist/index.html および 広島県電子納品検査ビューア.html が生成されます
```

## 🌐 Render (Render.com) へのデプロイ手順

本アプリは Render の **Static Site（静的サイト）** として無料かつ高速に公開できます。

### デプロイの流れ
1. **GitHubリポジトリの作成**:
   この `cals-inspection-viewer` フォルダの内容を GitHub のリポジトリにプッシュします。
2. **Render で新規作成**:
   * [Render ダッシュボード](https://dashboard.render.com/) にアクセスし、**「New」→「Static Site」** を選択します。
   * プッシュした GitHub リポジトリを選択します。
3. **設定内容**:
   リポジトリ内の `render.yaml` により自動入力されますが、手動設定する場合は以下を指定します：
   * **Name**: 任意（例: `hiroshima-cals-viewer`）
   * **Branch**: `main` (または `master`)
   * **Build Command**: `npm install && npm run build`
   * **Publish Directory**: `dist`
4. **「Create Static Site」をクリック**:
   数分でビルドが完了し、`https://xxxx.onrender.com` という公開URLが発行されます。

> **🔒 セキュリティに関する安心事項**  
> クラウド（Render）上にアプリを公開した場合でも、ユーザーが選択した電子納品フォルダや工事写真・書類のデータが **Render サーバーに送信されることは一切ありません**。すべてのデータ解析はアクセスした利用者のブラウザ（PCローカル）内でのみ完結します。
